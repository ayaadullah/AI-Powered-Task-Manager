# AI-Powered Task Manager

An AI-powered full-stack task management application built with React, FastAPI, PostgreSQL, and the Claude API.

## Project Goals

- Manage tasks with a clean, responsive dashboard
- Authenticate users securely
- Store tasks and AI generations in PostgreSQL
- Use Claude to generate, break down, and prioritize tasks
- Build a production-style REST API
- Deploy the application with a documented architecture
